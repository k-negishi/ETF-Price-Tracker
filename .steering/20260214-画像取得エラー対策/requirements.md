# 要件定義

## 機能名
画像取得エラー対策 (LINE送信失敗の修正)

## 背景
VTの6ヶ月株価チャート画像がLINEに送信されない事象が発生している。
**調査結果: S3には画像が正常に生成・アップロードされていることを確認済み。**
問題箇所は **LINE Messaging APIへの画像送信処理**。

## 問題の特定
- ✅ チャート生成: 正常動作
- ✅ S3アップロード: 正常動作
- ❌ **LINE画像送信: 失敗している**

## 原因の可能性
1. **presigned URLの問題**
   - 有効期限切れ (現状3600秒 = 1時間)
   - URL形式の問題 (クエリパラメータのエンコーディング等)

2. **LINE Messaging API側の制限**
   - 画像サイズ制限超過 (最大10MB, 推奨1MB以下)
   - 画像形式の問題
   - LINE側からS3へのアクセス失敗 (ネットワーク、タイムアウト等)

3. **S3バケットポリシーの問題**
   - presigned URLでアクセス可能だが、LINE APIからアクセス不可の可能性

4. **エラーハンドリング不足**
   - handler.py:151-152 でエラーをキャッチしてログ出力のみ
   - 具体的なエラー内容が不明

## 要件
### 必須要件
1. **LINE画像送信失敗時の詳細ログ出力**
   - エラーの種類 (HTTPステータス、エラーメッセージ)
   - presigned URLの検証
   - 画像ファイルサイズの記録

2. **画像サイズの確認と最適化**
   - 現在のチャート画像サイズを確認
   - LINE API制限 (10MB) 内に収まっているか検証
   - 必要に応じてチャート生成時のdpi調整

3. **presigned URL有効期限の延長**
   - 現状3600秒 → より長い期限に変更 (例: 86400秒 = 24時間)

4. **LINE画像送信のリトライメカニズム強化**
   - 現状のリトライロジック確認
   - 必要に応じてリトライ回数・間隔の調整

### 任意要件
1. 画像送信成功/失敗をテキスト通知に含める
2. presigned URLの事前検証 (HEAD リクエスト等)
